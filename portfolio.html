##About me

Quality is a mindset, not a phase.

I'm a detail-oriented QA Test Engineer with a Bachelor's in Computer Science. I design and execute comprehensive manual test suites for web and mobile applications across multiple platforms, starting from how a system is supposed to behave and then exploring every way it might not.

My bug analysis goes beyond "it's broken." I isolate reproducible steps, document each defect clearly in Jira, and work closely with developers to verify fixes, which shortens the release cycle and builds trust between QA and engineering.

Because I also build web applications (HTML/CSS, JavaScript, PHP, MySQL), I speak both languages and review features with a builder's empathy and a tester's skepticism. I'm committed to continuous learning and to applying modern testing methodologies.
